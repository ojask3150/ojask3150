## 🔥 Sagas (Projects)

### 🌾 Saga 1: The Crop Type Mapping Saga
**`Pixel-Based ML → Transformer Architecture`** &nbsp;|&nbsp; *Feb 2026 – Aug 2026*

> *"From base form to Super Saiyan: XGBoost evolves into a Transformer."*

| Stat | Value |
|------|-------|
| 🥋 **Form 1: XGBoost + SMOTE** | **95.8%** accuracy on 87 local parcels |
| ⚡ **Form 2: 3-layer Transformer Encoder** | **71.4%** overall accuracy across 18 classes |
| 🛰️ **Input** | 13-band Sentinel-2 time-series (45 passes/year) with calendar encodings |
| 🌱 **Wheat vs. Mustard** | **95%** validation accuracy |

- Built an end-to-end pipeline, from pixel-based ML to a self-attention Transformer over Sentinel-2 time-series.
- Fixed a production calibration mismatch where live accuracy crashed from **90% to 12%**, by coupling training directly to live **CDSE API** feeds.
- Engineered **zero-padding band expansion** to transfer pre-trained 13-band European weights onto 4-band Indian field data.
- Shipped an interactive dashboard with parcel browsing, live prediction endpoints, and automated **GeoTIFF** map generation for GIS.

`PyTorch` `TensorFlow` `XGBoost` `Scikit-learn` `Leaflet` `GeoPandas` `QGIS` `GDAL`

### 🌲 Saga 3: The Deforestation Detection Saga
**`U-Net on Sentinel-2 Imagery`** &nbsp;|&nbsp; *April 2026*

> *"Detecting forest loss from space, like sensing Ki across the planet."*

- Built a **PyTorch U-Net** for pixel-level deforestation mapping from 4-band 10m Sentinel-2 imagery, reaching **91.16% accuracy** across 400 km² of test areas.
- Implemented a **64-stride sliding window** pipeline for large raster inference.
- Tuned decision thresholds to lift **IoU from 1.40% → 49.92%**. 📈

`PyTorch` `U-Net` `Rasterio` `NumPy` `Scikit-learn` `Matplotlib` `QGIS` `GDAL`

### 🚜 Saga 4: ML for Agricultural Monitoring
**`Multi-Season Crop Performance Modeling`** &nbsp;|&nbsp; *February 2026*

> *"120 million pixels. Zero fear."*

- Processed **120M pixels** of 10m Sentinel-2 imagery across **4 seasons** in Haryana, India.
- Engineered **16 spectral features per season**: raw bands plus 12 vegetation indices (NDVI, EVI, SAVI, NDWI).
- Trained and compared **5 algorithms** (XGBoost, Random Forest, Gradient Boosting, Decision Tree, Linear Regression) on 100K samples.
- Found key limits of pixel-level regression without environmental variables via spatial correlation analysis.

`Python` `Scikit-learn` `XGBoost` `Rasterio` `QGIS` `GDAL` `Pandas` `NumPy`
